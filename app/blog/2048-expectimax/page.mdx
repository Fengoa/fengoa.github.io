# 2048 Expectimax：查表启发式与迭代加深

站上有一局可交互的 [2048 Arena](/2048)，控制台里还能粘贴 `scripts/2048-ai-console.js` 让 bot 自己推盘。这篇文章写的是后者背后的搜索：为什么 Expectimax 适合 2048、nneonneo 那套行启发式在算什么，以及浏览器里怎么用有限时间把深度提上去。

封面里那块奶油色棋盘在自动落子。完整版搜索更重，封面用的是同一套局面编码下的轻量启发，方便一眼看到「机器在推盘」的节奏。

## 局面不是双人博弈

2048 的对手不是另一个玩家。你每走一步，系统在空格上以约 90% 概率放 2、约 10% 概率放 4，位置均匀随机。搜索树上交替出现两类节点：

**Max 节点**：轮到你，在 `up / down / left / right` 里选一个合法方向，目标是最大化后续期望收益。

**Chance 节点**：轮到环境，对每个空格 × 两种新生面值求加权平均。

经典 Minimax 假设对手总选对你最不利的分支。这里环境按固定分布抽样，把「最坏」换成「期望」就得到 Expectimax：

<Math block>{`V_{\\max}(s) = \\max_{a} V_{\\mathrm{chance}}(s, a)`}</Math>

<Math block>{`V_{\\mathrm{chance}}(s, a) = \\sum_{s'} P(s'|s,a)\\, V_{\\max}(s')`}</Math>

叶节点不再继续展开时，用启发式函数 <Math>{`H(s)`}</Math> 估值。整棵树估的是：从当前局面继续走下去，期望能落到多好的盘面。

## 16 位一行：把 4×4 压进查表

Naive 实现会在递归里反复扫描 16 个格子、现场压缩一行。nneonneo 的做法是把每一行编成 16 位整数：四个格子各占 4 bit，存的是 <Math>{`\\log_2`}</Math> 后的阶（空为 0，2 为 1，4 为 2，……）。整盘就是四个 `uint16`。

启动时预计算 65536 种行状态的：

左移 / 右移结果、该行得分增量、空格数，以及后面启发式要用的若干项。列方向先做转置，再复用行表。一次移动变成几次查表与位运算，Expectimax 才能在浏览器里每步扩出几十万到上百万节点。

## 启发式：空格、合并、单调、面值和

叶节点估值是八次查表之和：四行加四列。单行的核心结构可以写成：

<Math block>{`H_{\\mathrm{row}} = C_{\\mathrm{lost}} + w_e E + w_m M - w_{\\mathrm{mono}}\\min(L,R) - w_s S`}</Math>

其中 <Math>{`E`}</Math> 是空格数，<Math>{`M`}</Math> 统计可合并对，<Math>{`L/R`}</Math> 是两个方向的单调性惩罚，<Math>{`S`}</Math> 是阶的幂次和。系数来自公开的 CMA-ES 调参结果（空格 270、合并 700、单调 47 等）。

直觉很直接。空格多，局面更活；能合并的邻对接得多，短期有分、盘面也更整齐；单调性鼓励「大块靠一侧、小块顺坡」，减少高阶块被夹在中间；面值和项抑制「一堆中等块挤在一起却合不出去」的板结。列用同一套表再评一遍，等于同时照顾横向与纵向的坡度。

这套 <Math>{`H`}</Math> 不保证最优，但和深度搜索叠在一起时，固定深度 4 的自对弈已经能稳定摸到十万量级分数；更深、更长时限会继续抬高 8192 / 16384 的出现率。

## 迭代加深与时间预算

浏览器里不能按固定深度死算。控制台脚本用迭代加深：从较浅的完整深度起，在时限内一层层往上加。某一层四个方向都搜完，才采纳该层的最佳着；超时则退回上一层完整结果，不使用半截根节点评估。

拥挤盘面空格少，分支因子下降，起始深度可以抬高；开局空格多，先保证浅层搜完。置换表按「当前深度上限」缓存 chance 节点估值，换深度时清空，避免浅层结果污染深层。

根节点还会按启发分给合法方向排个序，让好棋更早被完整评估。时限触顶时，至少手里还有一个已经比完的候选。

## 接到真实页面上的坑

算法对了，挂到带动画的页面上仍可能「看起来很聪明、分数却只有几百」。Arena 的滑动大约 180ms，合并弹动更长。若按键间隔压到几十毫秒，大量输入会在 `animating` 期间被丢掉，bot 等于拿过期棋盘决策。

读盘也要避开动画中帧：合并过程中两块会短暂叠在同一格，若用 `Math.max` 合并数值，会少算一块。可靠流程是：棋盘稳定 → 思考 → 发一次方向键 → 等到指纹变化并再次稳定 → 再进入下一步。深度日志里的「12」在强概率剪枝下也不等于真正展开了 12 层，上限收一收可以减少误导。

## 自己跑一把

打开 [/2048](/2048)，F12 控制台粘贴仓库里的 `scripts/2048-ai-console.js`，执行：

```js
start2048AI(200)
```

第二参数是步后额外间隔；真正的节奏由「等动画结束」控制。需要停手时调用 `stop2048AI()`。

Node 里也可以自对弈压测：

```bash
node scripts/2048-ai-console.js --bench 4 4
```

固定深度 4 时，多局平均分通常落在十余万到二十万一带，具体随随机种子波动。

## 还没放进控制台脚本的东西

学术路线上还有 N-tuple 网络 + TD-afterstate、多阶段 TD 等，公开结果可以把平均分再抬一个数量级，权重大、不适合整段粘进控制台。当前脚本刻意停在「查表启发 + Expectimax + 迭代加深」：单文件、可解释、在现代浏览器里实时可玩。

若要把同一套搜索嵌进 Arena 的脚本编辑器，导出 `chooseMove(board)` 即可对接现有 runner；深度与时限可以按「演示」和「冲分」分成两档配置。
