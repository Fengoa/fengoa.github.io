# 线性代数：深度学习用到的那些

不讲证明，只讲直觉和用途。每个概念都会对应到推荐系统或大模型的具体场景。

---

## 向量：一切的起点

一个向量就是一组有序的数字：

```text
用户 embedding:  [0.3, -0.8, 0.5, 0.1]
电影 embedding:  [0.2, -0.6, 0.7, 0.3]
token embedding: [0.1, 0.4, -0.2, ..., 0.8]  ← 128维或更高
```

**直觉**：向量是高维空间中的一个"点"或"方向"。两个 embedding 在空间中距离近，意味着语义相似。

### 向量长度（范数）

```text
‖v‖ = √(v₁² + v₂² + ... + vₙ²)
```

归一化（让长度=1）后，向量只保留"方向"信息：

```text
v̂ = v / ‖v‖
```

**用在哪**：双塔召回时，user 和 item embedding 都做 L2 归一化后再算余弦相似度。

---

## 点积：衡量"方向一致性"

两个向量的点积：

```text
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
```

几何含义：

```text
a · b = ‖a‖ × ‖b‖ × cos(θ)
```

- 方向相同 → 正值（大）
- 方向垂直 → 零
- 方向相反 → 负值

**用在哪**：

| 场景 | 点积在做什么 |
|------|-------------|
| 双塔召回 | user_emb · item_emb = 用户对物品的兴趣分 |
| Attention | Q · K = 当前 token 对历史 token 的关注度 |
| 余弦相似度 | 归一化后的点积 = cos(θ) |
| 分类层 | hidden · weight = logit（未归一化分数） |

Attention 的核心计算 `Q × K^T` 本质就是**对所有位置做批量点积**。

---

## 矩阵乘法：批量线性变换

一个矩阵乘向量 = 对向量做线性变换（旋转+缩放+投影）：

```text
W × x = y
(m×n)(n×1) = (m×1)

输入 n 维 → 输出 m 维
```

**直觉**：矩阵是一台"变换机器"。输入一个向量，输出另一个向量。每个神经网络层就是一个矩阵乘法 + 激活函数。

两个矩阵相乘：

```text
A × B = C
(m×k)(k×n) = (m×n)
```

规则：A 的列数 = B 的行数。结果 C[i][j] = A 的第 i 行点积 B 的第 j 列。

**用在哪**：

```text
# 全连接层
output = input × W + b       ← (batch, in) × (in, out) = (batch, out)

# Attention 的 QKV 投影
Q = input × Wq               ← (seq_len, d_model) × (d_model, d_head) = (seq_len, d_head)

# Attention 分数
scores = Q × K^T              ← (seq_len, d_head) × (d_head, seq_len) = (seq_len, seq_len)
```

最后那个 `(seq_len, seq_len)` 矩阵就是注意力权重——第 i 行第 j 列表示位置 i 对位置 j 的关注程度。

---

## 转置：行列互换

```text
A =  [1 2 3]      A^T = [1 4]
     [4 5 6]            [2 5]
                        [3 6]
```

**为什么 Attention 要 Q × K^T？**

Q 和 K 的形状都是 `(seq_len, d_head)` — 每行是一个位置的向量。

我们想算"每对位置之间的点积"，需要 Q 的行 和 K 的行 做点积。但矩阵乘法是"行×列"，所以要把 K 转置一下：

```text
Q × K^T = 每行Q和每行K的点积矩阵
(s, d)(d, s) = (s, s)  ← 所有位置对之间的相似度
```

---

## 正交：互不干扰

两个向量正交 = 点积为 0 = 方向完全无关。

**为什么重要**：

- 多头注意力的不同 head 如果方向正交，它们在提取"互不干扰"的信息
- Embedding 初始化用正交矩阵，避免不同维度一开始就高度相关
- LayerNorm 的效果之一是让特征更接近正交分布

**正交矩阵**：所有列向量两两正交且长度为 1。

```text
Q^T × Q = I（单位矩阵）
```

性质：正交矩阵做变换只旋转，不缩放。向量长度不变。这就是 RoPE 的核心——用正交旋转矩阵编码位置，不改变向量的大小信息。

---

## 特征值与特征向量

一个方阵 A 乘以某些特殊向量后，方向不变，只缩放：

```text
A × v = λ × v

v 是特征向量（方向不变的那个向量）
λ 是特征值（缩放倍数）
```

**直觉**：特征向量是矩阵"最喜欢"的方向——沿这个方向推，东西只会变大或变小，不会偏转。

**用在哪**：

- **PCA（主成分分析）**：协方差矩阵最大的几个特征向量 = 数据中方差最大的方向 = 最重要的特征
- **图卷积网络**：图的拉普拉斯矩阵特征值 = 图的频率成分
- **训练稳定性**：梯度矩阵（Hessian）的特征值过大 → 训练不稳定

---

## SVD：任何矩阵都能拆

奇异值分解（SVD）把任意矩阵拆成三部分：

```text
A = U × Σ × V^T

A: (m×n) 原始矩阵
U: (m×k) 左奇异向量（行空间的基）
Σ: (k×k) 奇异值对角矩阵（重要程度）
V: (n×k) 右奇异向量（列空间的基）
```

**直觉**：任何线性变换都可以分解为"旋转 → 缩放 → 再旋转"。Σ 里的奇异值按大小排列，越大越重要。

### 低秩近似

只保留前 r 个最大的奇异值：

```text
A ≈ U_r × Σ_r × V_r^T
```

原来存 m×n 个数，现在只存 (m+n)×r 个数。如果 r 远小于 m、n，压缩比极高。

**用在哪**：

| 场景 | SVD 在做什么 |
|------|-------------|
| 推荐系统矩阵分解 | 用户-物品评分矩阵 ≈ 用户矩阵 × 物品矩阵（这就是我们 vector-recall 那篇干的事） |
| LoRA | 冻结原始权重 W，只训练 ΔW = B×A，其中 B(d,r), A(r,d)，r=8-64 |
| 模型压缩 | 把大权重矩阵用低秩近似替代 |
| PCA | 协方差矩阵的 SVD → 取前 k 个主成分 |

我们做的**向量召回**本质就是对评分矩阵做低秩分解：

```text
Rating(user, item) ≈ user_embedding · item_embedding
(M×N)             ≈ (M×64) × (64×N)

把 M×N 的稀疏矩阵压缩到两组 64 维向量
```

---

## 旋转矩阵：RoPE 的数学基础

二维旋转矩阵：

```text
R(θ) = [cos θ  -sin θ]
       [sin θ   cos θ]
```

把向量 v 旋转 θ 角度：

```text
R(θ) × v = 旋转后的 v
```

关键性质：
- 旋转不改变向量长度（`‖R(θ)v‖ = ‖v‖`）
- 两个旋转后的向量的点积只取决于**相对旋转角度**

**RoPE 位置编码利用的就是第二条性质**：

```text
给位置 m 的 Q 旋转 mθ
给位置 n 的 K 旋转 nθ

Q_m · K_n 的点积中，角度 mθ 和 nθ 的差 = (m-n)θ
→ 点积只取决于相对位置 (m-n)，不取决于绝对位置
```

这就是为什么 RoPE 天然支持外推到训练时没见过的长度——模型学习相对关系，不涉及绝对位置。

高维版本：把 d 维向量拆成 d/2 对，每对用不同频率的旋转矩阵，频率从低到高（类似傅里叶变换）。

---

## 秩：信息的"有效维度"

矩阵的秩 = 线性无关的行（或列）的数量 = 信息的真实维度。

```text
满秩：每行都提供独立信息
低秩：有冗余，很多行可以被其他行表示
```

**用在哪**：

- **LoRA 的核心假设**：微调时权重的变化量 ΔW 是低秩的（秩 r=8-64 就够了），所以不需要更新全部参数
- **Embedding 表的秩**：百万物品的 64 维 embedding 表，真正有效的维度可能只有 20-30
- **注意力矩阵的秩**：实验发现很多注意力矩阵是低秩的 → 这是 GQA（多 Q 共享 KV）能 work 的原因

---

## 对应关系总结

| 线代概念 | 深度学习中的身份 |
|---------|----------------|
| 向量 | Embedding（用户/物品/token 的表示） |
| 点积 | 相似度计算、Attention 分数 |
| 矩阵乘法 | 每一层的线性变换、QKV 投影 |
| 转置 | Attention 中 Q×K^T 的形状对齐 |
| 正交 | 初始化策略、多头的独立性、RoPE 保长 |
| 特征值 | PCA 降维、训练稳定性分析 |
| SVD / 低秩 | 矩阵分解召回、LoRA、模型压缩 |
| 旋转矩阵 | RoPE 位置编码 |
| 秩 | LoRA 的 r、GQA 的理论基础 |

## 验证直觉的代码

不用推导，执行一遍即可验证直觉：

```python
import numpy as np


# 1. 点积 = 相似度
user = np.array([0.3, -0.8, 0.5])
movie_a = np.array([0.2, -0.7, 0.6])  # 相似
movie_b = np.array([-0.5, 0.3, -0.1]) # 不相似

print(f"user·movie_a = {user @ movie_a:.3f}")  # 正值大 → 推荐
print(f"user·movie_b = {user @ movie_b:.3f}")  # 负值 → 不推荐


# 2. 矩阵乘法 = Attention
Q = np.random.randn(4, 8)  # 4个位置，8维
K = np.random.randn(4, 8)

scores = Q @ K.T            # (4,4) 每对位置的相似度
print(f"\nAttention scores:\n{scores.round(2)}")


# 3. SVD = 低秩分解（推荐系统）
ratings = np.random.randn(100, 50)  # 100用户×50电影
U, S, Vt = np.linalg.svd(ratings, full_matrices=False)

# 只保留前8维 → 和我们64维embedding同理
ratings_approx = U[:, :8] @ np.diag(S[:8]) @ Vt[:8, :]
error = np.linalg.norm(ratings - ratings_approx) / np.linalg.norm(ratings)
print(f"\n用8维近似百维矩阵，相对误差: {error:.2%}")


# 4. 旋转矩阵 = RoPE
def rotate(v, theta):
    R = np.array([[np.cos(theta), -np.sin(theta)],
                  [np.sin(theta),  np.cos(theta)]])
    return R @ v

v = np.array([1.0, 0.0])
v_rot = rotate(v, np.pi/4)  # 旋转45度

print(f"\n旋转前长度: {np.linalg.norm(v):.3f}")
print(f"旋转后长度: {np.linalg.norm(v_rot):.3f}")  # 长度不变！
```
