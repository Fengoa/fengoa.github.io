# 机器学习的 7 个核心概念

不讲证明，只讲直觉。每个概念一句话说清楚，然后对应到代码的哪一行。

---

## 1. 机器学习：让数据说话

传统编程：人写规则，机器执行。

```text
if 温度 > 30 and 湿度 > 70:
    return "体感闷热"
```

规则越来越多就写不过来了。机器学习反过来——给一堆"输入→输出"的例子，让机器自己找规则：

```text
输入: [温度=35, 湿度=80] → 输出: 闷热
输入: [温度=20, 湿度=30] → 输出: 舒适
输入: [温度=5, 湿度=90]  → 输出: 阴冷
... 给 1000 条这样的数据

机器自己学到: f(温度, 湿度) → 体感
```

语言模型也是一样：给一堆文本，让模型学"给定前面的字，下一个字是什么"。没有人手写规则说"the 后面跟 cat"，模型自己从数据里学到的。

---

## 2. Loss：模型有多"惊讶"

怎么量化模型的好坏？用 loss（损失函数）。

**直觉：loss = 模型对正确答案有多惊讶。**

```text
模型预测"下一个字是 'e'"的概率：

P('e') = 0.95  →  loss = -log(0.95) = 0.05  ← 几乎不惊讶
P('e') = 0.50  →  loss = -log(0.50) = 0.69  ← 有点意外
P('e') = 0.01  →  loss = -log(0.01) = 4.60  ← 非常惊讶！
```

训练的目标就是**让 loss 越来越小**——让模型对正确答案越来越不惊讶。

对应到代码：

```python
loss = F.cross_entropy(logits, targets)  # 计算模型的"惊讶程度"
```

大模型系列里 `val loss = 4.17` 就是"65 选 1 瞎猜的惊讶程度"（ln(65)=4.17）。训练后降到 1.58，说明模型已经很"确定"下一个字该是什么了。

---

## 3. 梯度下降：往山下走一步

知道 loss 了，怎么让它变小？

把 loss 想象成一座山——横轴是模型参数，纵轴是 loss 值。我们站在山上，要找到最低点。

```text
loss
  │  ╱╲
  │ ╱  ╲      ← 我们在这里
  │╱    ╲
  │      ╲╱   ← 想到达这里（最低点）
  └──────── 参数
```

**梯度** = 当前位置的坡度方向（往哪边走 loss 上升最快）。

**梯度下降** = 往梯度的反方向走一步（下坡）。

**Learning Rate** = 每步走多远。太大会跳过最低点，太小永远走不到。

对应到代码：

```python
loss.backward()     # 计算梯度（山坡的方向）
optimizer.step()    # 参数往反方向移动一步（下山）
```

每调用一次这两行，模型就"聪明一点点"。训练 10000 步 = 下山走了 10000 步。

---

## 4. 反向传播：自动算梯度

一个参数好办，百万个参数的梯度怎么算？

**链式法则**：复合函数的导数 = 各层导数相乘。

```text
y = f(g(h(x)))
dy/dx = f' × g' × h'   ← 链式法则
```

Transformer 有几十层嵌套的计算。PyTorch 在你做前向计算时自动记录了整个计算图，调用 `loss.backward()` 时从输出倒推每一层的梯度。

你不需要手写任何导数公式。只需要：

```python
loss = model(x, targets)  # 前向：算 loss（PyTorch 自动记录计算图）
loss.backward()           # 反向：从 loss 倒推所有参数的梯度
optimizer.step()          # 更新：用梯度调整参数
optimizer.zero_grad()     # 清零：为下一步准备
```

这四行就是整个训练循环的核心。所有深度学习模型——CNN、RNN、Transformer、GPT-4——训练的本质都是这四行。

## 5. 神经网络：矩阵乘法 + 激活函数

线性模型（y = wx + b）只能画直线。现实世界的关系不是线性的。

解法：**矩阵乘法交替激活函数，堆多层**。

```python
# 一层神经网络
x = input                    # 输入
x = Linear(x)               # 矩阵乘法（线性变换）
x = ReLU(x)                 # 激活函数（引入非线性）
x = Linear(x)               # 再一次线性变换
output = x
```

为什么有效？数学上证明了：两层网络 + 足够多的神经元，能逼近**任意**连续函数。层数越多、神经元越多，能学的模式越复杂。

对应到大模型里的 FFN（前馈网络）：

```python
class FFN(nn.Module):
    def __init__(self, n_embd):
        self.net = nn.Sequential(
            nn.Linear(n_embd, 4 * n_embd),  # 扩大 4 倍
            nn.GELU(),                       # 激活函数
            nn.Linear(4 * n_embd, n_embd),  # 缩回来
        )
```

就是两层全连接 + 激活。Transformer 里每个 block 都有一个。

## 6. Embedding：把离散的东西放进连续空间

神经网络只认连续的数字。但 token 是离散的——"a" 是 0 号，"b" 是 1 号，"c" 是 2 号。0、1、2 之间没有"距离"的概念。

**Embedding = 给每个离散的东西分配一个可学习的向量。**

```python
embedding = nn.Embedding(65, 128)  # 65 个 token，每个用 128 维向量表示

# "a"(0号) → [0.12, -0.34, 0.56, ...]  一个 128 维向量
# "b"(1号) → [-0.23, 0.45, 0.78, ...]  另一个 128 维向量
```

训练之后，语义相似的 token 的向量会自然靠近：

```text
"king" 和 "queen" 的 embedding → 距离近
"king" 和 "apple" 的 embedding → 距离远
```

没有人告诉模型"king 和 queen 相似"——它从数据里自己学到的（因为它们出现的上下文相似）。

推荐系统里的"用户向量"和"物品向量"也是 embedding——把用户/物品放进同一个连续空间，距离近 = 用户喜欢这个物品。

## 7. 过拟合：背答案 vs 学规律

```text
训练集 loss: 0.46  ← 完美！
验证集 loss: 7.90  ← 灾难！
```

模型在训练数据上表现完美，但在新数据上很差——它**背住了训练数据的答案**，未能归纳普适规律。就像学生把历年考题背了，但不会做新题。

**判断标准**：train loss 持续下降，val loss 先降后升 → 过拟合了。

```text
step  1500 | train 4.13 | val 5.77  ← val 最低点（最佳模型）
step  5000 | train 1.12 | val 7.12  ← val 在涨（过拟合了）
step 10000 | train 0.46 | val 7.90  ← 背答案到极致
```

**根本原因**：模型容量（参数量）>> 数据量。4M 参数去记 267K token 的数据，绰绰有余——直接背下来比"学规律"更容易让 train loss 降低。

**解决方法**：
- 加数据（最有效，也最贵）
- 减小模型（但太小学不到东西）
- Early Stopping（val loss 开始涨就停）
- Dropout（训练时随机关闭神经元，防止"共谋背答案"）
- Weight Decay（让参数倾向于小值，限制模型记忆容量）

Scaling Law 的核心结论就是关于这个：**参数量和数据量要匹配**。工业界用万亿 token 训练万亿参数，不存在过拟合问题——数据远比模型大。

## 串起来

一次训练的完整流程：

```python
# 准备
model = Transformer(...)                    # 随机初始化参数
optimizer = AdamW(model.parameters(), lr=3e-4)

# 循环 10000 次
for step in range(10000):
    x, y = get_batch(data)                  # 取一批训练数据
    logits = model(x)                       # 前向：输入 → 预测
    loss = cross_entropy(logits, y)         # 算 loss（多惊讶）
    loss.backward()                         # 反向传播（算每个参数的梯度）
    optimizer.step()                        # 梯度下降（参数往 loss 变小的方向调）
    optimizer.zero_grad()                   # 清零梯度，准备下一轮
```

**这就是全部。**

不管是线性回归、CNN、Transformer 还是 GPT-4，训练的本质都是这个循环。区别只在于 model 的结构有多复杂、data 有多大、循环执行多少次。
