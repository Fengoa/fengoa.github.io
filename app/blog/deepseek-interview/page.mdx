# 梁文锋访谈：开源、克制与 AGI 路线图

这篇长文按主题整理了梁文锋围绕 DeepSeek 的一系列看法。从为什么坚持开源，到 API 怎么定价，再到 AGI 如何一步步走通，以及中美之间真正的差距落在哪里。

## 出发点：善意，而非上市

公司成立时，目标不是赚钱，也不是上市。我们想做的是对世界有用的事，出发点是善意。

愿景不是写给人看的标语，它真正驱动公司的方式体现在每天怎么做。我们靠愿景而不是 KPI 或制度来组织团队。每个人对愿景的理解不完全一样，方向是一致的。

## 开源是本来要做的事

开源是愿景本身的要求，是我们本来就要做的，不是被逼出来的。AI 市场足够大，将来可能占到 GDP 的十分之一，没有谁能独占，必须分享。克制一点，才能做成。

开源和商业化不冲突，前提是只赚合理的利润，比如大约六倍、十个月回本。想赚暴利，开源才会成为负担。我们开源的模型和自部署的模型完全一致，不担心别人拿去竞争，甚至愿意帮别人部署。

## 定价：十个月回本，不追求最大化

定价的原则是十个月收回设备成本，不追求利润最大化。

在需求缺乏弹性的区间，即便提价，收入也不会明显增加，所以不如保持低价。降价让我们团队开心，也符合让更多人用得起的初衷。

## 克制是一种战略

克制体现在很多地方：不抢 C 端用户，不急着变现，也不想成为下一个超级 App。

眼前的小利益是芝麻，后面的 AGI 才是西瓜，克制能提高做成 AGI 的概率。去年 C 端用户爆发，我们没有刻意留住他们或着急变现，只是尽量服务好。

## 通往 AGI 的阶梯

当前这一级台阶是：思维链（CoT）→ 智能体（Agent）→ 持续学习（让模型像人一样长期学习）→ 奇点（自我迭代）→ 具身智能（进入现实世界）。每一步都站在前一步之上，不会白走。

下一个必须突破的瓶颈是持续学习。一旦走通，AI 就能自我改进，通用智能也就不远了。

## C 端和 B 端都是副产品

C 端和 B 端业务都是做 AGI 路上自然长出来的，不是主要目标。

站在 AGI 的技术高位做应用，会形成降维打击。我们没怎么刻意投入，结果却不错。去年 C 端用户赶都赶不走，今年 B 端收入增长也乐观，但公司内部不把这些看成最重要的事。

## 唯一不让步的，是团队

公司唯一不能退让的核心利益是团队稳定。只要人不散，AGI 一定做得成。

钱和资源都好找，人才是最难的挑战。融资之后用期权激励，缓解了一部分风险。我们的人才流动率比同行低，因为大家是被 AGI 这个愿景吸引过来的。

## 差距在算力，不在人

人才上的差距不大。根本差距在算力：实验机会少，能做的模型规模也受限。

美国已经用上 800B 激活的模型，中国还停留在几十 B 激活。中国要训练同等规模的模型，需要大约 5 万张 GB300，或者 20 万张华为 950。差距大概在 12 到 18 个月，但算力只有美国的二十分之一。弥补的办法只能靠效率上的创新。

## 终局看三件事

最后比的是三件事：成本、时间、用户体验。成本最重要；时间带来先发优势；用户体验形成粘性。

成本压得够低，就能在竞争里筑起壁垒。

## 国产芯片的机会

英伟达的 CUDA 生态正在被快速瓦解，原因有几条：AI 辅助写代码、TileLang 这类高级语言的出现、专用计算卡市场超过了游戏卡。

国产芯片，尤其是华为，正面临一次历史性的机会，生态问题有望在一年内解决，但产能还是瓶颈。华为 950 对比英伟达 GB200/GB300 的性能差距，大约是四倍卡数加上两年时间。

## 不去做自己不擅长的事

我们只想做自己最擅长的一块，不去做芯片，也不向上游延伸，聚焦在 AI 本身。

自建集群是必要的，但自研芯片要看成本效益，我们更希望以合理的价格买到芯片。

## 多模态是零件，Scaling 仍是主线

多模态是个组件，不是智能的主线，但我们会做。

我们仍然相信 Scaling，规模越大效果越好。中国离 Scaling 的上限还很远，主要卡在算力。模型做到现在的规模，是依据手头能用的资源决定的，不是我们认为这个规模已经够了。

## 低成本是被迫，也是本意

低成本既是愿景的一部分，也是算力有限之下的必然选择，我们因此有很强的动机把效率做上去。

大公司没有追求低成本的动力，低成本会拉低它们的收入。DeepSeek 的团队有同理心，希望别人也用得起。效率提升了，同样的算力就能训更大的模型。

## 两条线：项目与探索

管理上有两条线。一条自上而下，是正式项目，比如发版；一条自下而上，是自由探索，没有 KPI。

正式工作占的时间不超过一半，剩下的一半员工可以研究自己感兴趣的问题。我们不加班。因为聚焦和克制，要做的事本来就不多，松弛的环境更利于研究和创新。决策靠共识，不是创始人一个人说了算。

## 持续学习：还没走通的一步

持续学习全世界都还在摸索，还没有有效的方法。思路有很多，但还没打通。

这件事不怎么消耗资源，主要是人想、人聊，我们鼓励大家去摸奖。时间线说不准，但一旦突破，AGI 的进程会明显加速。

## 标数据，研究员也要下场

高质量数据标注成本高，美国没有优势，中国也没有成本优势。

我们的办法是两条腿走路：先标成本低的，核心研究员一半时间也在标数据。数据标注的瓶颈是时间，不是资本，预计一年内国内会有明显改观。

## 后训练会加码，但拼的是时间

我们会加大后训练的投入，但差距主要在时间，国外起步更早。

资本不是瓶颈，现有资本足够我们快速扩张。高质量数据标注靠时间积累，不是砸钱就能解决的。

## 最该做的垂直应用是 Coding Agent

眼下最重要的垂直应用是 Coding Agent，它能直接提升我们自己的研发效率，反过来加速 AGI。

金融、法律、医疗这些纵向 Agent 优先级低一些，商业模式还不清晰。

## 有保底的业绩，也有远处的梦

我们有商业基础，B 端有收入，C 端有用户，最坏的情况靠卖 API 也能支撑起一家上市公司。

公司已经接近净利润，以后可以同时满足科研和资本市场的要求。既有远大的梦，也有保底的业绩。

## 没有模板可抄

我们没有可以照搬的对象，像是贝尔实验室那样。每一步都是根据当时的情况，实事求是做出来的选择。

本质上我们是公司，必须考虑生存和商业化，但可以有利润以外的追求，而且这种追求反而帮了商业化。

## 用 TileLang 换掉 CUDA

我们用 TileLang 这种高级语言替代 CUDA 生态，开发效率大幅提高，代码量少很多。

性能损失只有百分之一到二，可以接受。这不是短期的妥协，而是技术上的机会。将来还可以用 AI 来写 TileLang，进一步加速。
