# 趁碎影还在

信息流渐渐地涨满了，在预告注意力的已经不多。算法又不是什么新鲜事，早把每一寸屏幕喂得很饱。通知的繁响在四近，短视频的残影在眼前：是昏沉的夜。

我关了所有 App，向后一仰，靠在椅背上；捏着一个还没写完的想法搁在脑子里。

我在蒙胧中，看见一个安静的页面。

---

这页面很简洁，克制，有呼吸。许多小的细节和小的动效，错综起来像一天云锦，而且万颗像素似的微微发光着，同时又展开去，以至于无穷。

我仿佛记得曾在很多安静的网站里经过。[Rauno](https://rauno.me) 的留白，[Paco](https://paco.me) 的节制，[Lee Robinson](https://leerob.com) 的清晰，[Vercel](https://vercel.com) 的网格与克制的动效，[wxad.design/abc](https://wxad.design/abc) 的交互分寸感，还有那些叫不出名字的个人站点……都倒映在我的收藏夹里，随着每一次翻阅，各各夹带了闪烁的灵感，并脑子里的产品逻辑、交互美学、代码架构，一同荡漾。诸影诸物，无不解散，而且摇动，扩大，互相融和；刚一融和，却又退缩，复近于原形。边缘都参差如夏云头，镶着屏幕光，发出水银色焰。凡是我所经过的网站，都是如此。

现在我脑子里的想法也如此。收藏夹的底子上，一切灵感统在上面交错，织成一篇，永是生动，永是展开，我看不见这一篇的结束。

一个产品逻辑在脑海里浮动，忽而碎散，拉长了，如缕缕的代码片段，然而没有落地。一种交互美学的直觉也在浮动，一段 CSS 布局的构想也在浮动。产品逻辑一条条全被拉长了，这时是泼剌奔迸的思绪。思绪织入交互中，交互织入代码中，代码织入审美中……。在一瞬间，它们又将退缩了。但那些碎片化的灵感影子也已碎散，伸长，就要织进彼此里去。

它们很美。但没有载体的灵感，终究只是水中倒影。

---

现在我所见的页面清楚起来了，简洁，克制，有呼吸，而且分明。屏幕上面，有无数小的细节和小的秩序，我一一看见，一一知道。

我看见页面边缘有一条光束在缓慢地移动。`BorderBeam`，从 [Magic UI](https://magicui.design) 借鉴来的。一个小方块沿着矩形边框走，80 秒绕一圈。技术上用了 CSS 的 [offset-path](https://developer.mozilla.org/en-US/docs/Web/CSS/offset-path)，让元素沿 `rect(...)` 路径运动。光束本身是一个带渐变的正方形——从金色到紫色再到透明，像一小截胭脂水沿着画框缓缓洇开。外层容器用了两层 CSS mask，取交集后只保留边框区域可见：

```css
mask: linear-gradient(transparent, transparent),
      linear-gradient(#000, #000);
mask-clip: padding-box, border-box;
mask-composite: intersect;
```

然后交给 Framer Motion 做 `offsetDistance` 从 0% 到 100% 的无限循环。匀速，安静，持续。这是"克制"二字的具象——不是没有动效，而是动效慢到你几乎注意不到，但去掉它，页面就会少一口呼吸。

我看见网格。不只是布局意义上的骨架，更是视觉语言上的秩序。我搭了一套 `Grid` 复合组件——`Grid.System`、`Grid.Cell`、`Grid.Cross`。每个网格容器根据行列数自动生成参考线，每个格子用绝对定位的 `div` 画右边框和下边框，相邻网格之间通过负 margin 让边框重叠，避免双倍粗线：

```tsx
<div
  className="flex flex-col [&>.grid+.grid]:mt-[calc(var(--guide-width)*-1)]"
  style={{ "--guide-width": `${guideWidth}px` }}
>
  {children}
</div>
```

当某些格子需要合并时（比如 Hero 区域横跨 10 列），内部多余的参考线要自动隐藏。`getHiddenBorders` 会遍历所有合并区域，判断当前格子是否在内部，如果是就把对应的边框去掉。`Grid.Cross` 在交叉点绘制一个小小的 SVG 十字——纯装饰，但它让网格从工具变成了语言。这些参考线在最终呈现时极浅，大多数人注意不到。但它们让一切都对齐了——像稿纸上的格线，你不看它，却始终在它的秩序里书写。这是"简洁"的具象。

我看见导航栏，四个入口：博客、品味、产品、我的。鼠标移上去，什么也不会立刻发生。要等一秒，图标才动；再等半秒，文字上有一道光扫过，持续 800 毫秒后消失；再等两秒，循环。一个自定义 hook `useHoverSequence` 编排这一切——核心是嵌套的 `setTimeout`，在每一步结束时检查鼠标是否还在，离开就立刻停止并清掉所有定时器：

```ts
const playSequence = useCallback(() => {
  iconRef.current?.startAnimation();
  addTimer(() => {
    if (!hoveredRef.current) return;
    setIsShimmering(true);
    addTimer(() => {
      setIsShimmering(false);
      addTimer(() => {
        if (!hoveredRef.current) return;
        playSequence();
      }, loopDelay);
    }, shimmerDuration);
  }, shimmerDelay);
}, [addTimer, shimmerDelay, shimmerDuration, loopDelay]);
```

文字闪光（`TextShimmer`）用了双层 `background-image` 配合 `background-clip: text`，底层纯色作基色，上层一条高亮渐变带通过 `backgroundPosition` 扫过。不急不缓，像河水推着一小片光斑慢慢漂过。这是"有呼吸"的具象。

我看见页脚的主题切换器，三个小图标：系统、亮色、暗色。`AnimatedBackground` 组件，基于 Framer Motion 的 `layoutId` 共享布局动画——所有按钮背后共享同一个半透明背景 div，点击时背景平滑地滑到被选中的按钮上。一个很小的交互，但用对了动画之后，切换变得自然得像翻书。

我看见博客的排版。MDX，在 `mdx-components.tsx` 里定义所有基础元素的样式映射。标题自动生成 `id` 配合目录锚点跳转，H2 上方一条短横线装饰，外链自动带右上角小箭头，有序列表用 CSS `counter` 自定义序号，代码高亮用 [sugar-high](https://github.com/huozhi/sugar-high)，不到 1KB，没有外部依赖。标题，装饰线，箭头，序号，高亮……也都各自分明。

光束，网格，导航序列，主题切换，排版细节——它们在页面上交错，织成一篇。那些脑子里曾经碎散的灵感，产品逻辑织入交互美学中，交互美学织入代码架构中，代码架构织入视觉秩序中……。每一个碎片都找到了自己的格子。

---

我就要凝视它们……。

我正要凝视它们时，骤然一惊，睁开眼，页面也已皱蹙，凌乱，仿佛有谁往平静的屏幕上掷了一条推送通知，思绪陡然起立，将整篇的构想撕成片片了。我无意识地赶忙捏住几乎熄屏的手机，眼前还剩着几点光标闪烁的碎影。

我真爱这一个安静的页面，趁碎影还在，我要追回它，完成它，留下它。我关掉通知，欠身伸手去敲键盘，——何尝有一丝碎影，只见昏暗的屏幕光，我不在那个安静的页面里了。

但我总记得见过这一篇好的页面，在昏沉的夜……。

所以我打开了编辑器。这个网站就是我"取笔"的动作——把脑海中那个好的故事，趁它还没有彻底碎散，沉淀下来的物理空间。

页脚写着 "Be quiet"。安静，但不是什么都没有。
