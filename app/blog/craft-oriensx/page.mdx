# 安静但不是什么都没有

做这个网站的时候，我一直在想一个问题：一个安静的页面，怎样才不会显得空洞？

答案藏在那些大多数人注意不到的地方——一条沿着边框缓慢移动的光束，极浅的网格参考线，鼠标悬停一秒后才开始的动画序列。它们都很小，但去掉任何一个，页面就会少点什么。

这篇文章记录搭建这个网站时的一些思考和实现。

## 设计垂点

动手之前我花了不少时间看别人的网站。[Rauno](https://rauno.me) 的站一直是我喜欢的，还有 [Paco](https://paco.me)、[Lee Robinson](https://leerob.com)。整体的视觉语言很大程度上参考了 [Vercel](https://vercel.com) 的设计——网格、留白、克制的动效，这些东西在 Vercel 的产品里已经被打磨得很成熟了，我没有理由不从中学习。

另一个对我影响很大的是 [wxad.design/abc](https://wxad.design/abc)。这个站让我意识到，一个个人站点可以同时是作品集、是设计表达、也是技术实验场。它对细节的处理方式——交互的节奏、动画的分寸感——给了我很多灵感。

它们有一个共同点：安静，但不无聊。

"安静"如果处理不好就会变成"空洞"。我需要找到一个垂点——一个细微的、持续的动态元素，让页面在安静中透出一点生命力。这个垂点最终是页面边缘的那条光束。

## 边框光束

`BorderBeam` 是我从 [Magic UI](https://magicui.design) 借鉴的组件。一个小方块沿着页面的矩形边框缓慢移动，80 秒绕一圈。

{/* TODO: 插入边框光束的录屏/动图 */}
{/* ![边框光束效果](/images/blog/craft-oriensx/border-beam.gif) */}

技术上，它用了 CSS 的 [offset-path](https://developer.mozilla.org/en-US/docs/Web/CSS/offset-path)，让元素沿着 `rect(...)` 路径运动。光束本身是一个带渐变的正方形——从金色到紫色再到透明，模拟彗星拖尾的效果。

比较巧妙的是遮罩处理。外层容器用了两层 CSS mask，取交集后只保留边框区域可见：

```css
mask: linear-gradient(transparent, transparent),
      linear-gradient(#000, #000);
mask-clip: padding-box, border-box;
mask-composite: intersect;
```

然后交给 Framer Motion 做 `offsetDistance` 从 0% 到 100% 的无限循环。匀速、安静、持续。这就是我要的那个"垂点"。

## 网格系统

网格是这个网站的骨架。不只是布局意义上的，更是视觉语言上的。

{/* TODO: 插入网格参考线的截图，展示参考线和十字交叉点 */}
{/* ![网格参考线](/images/blog/craft-oriensx/grid-system.png) */}

我搭建了一套 `Grid` 复合组件：`Grid.System`、`Grid.Cell`、`Grid.Cross`。它做的事情本质上很简单——生成 CSS Grid 容器和参考线，但细节不少。

每个网格容器会根据行列数自动生成参考线。每个格子用绝对定位的 `div` 画右边框和下边框，相邻网格之间通过负 margin 让边框重叠，避免双倍粗线：

```tsx
<div
  className="flex flex-col [&>.grid+.grid]:mt-[calc(var(--guide-width)*-1)]"
  style={{ "--guide-width": `${guideWidth}px` }}
>
  {children}
</div>
```

当某些格子需要合并时（比如 Hero 区域横跨 10 列），内部多余的参考线要自动隐藏。`getHiddenBorders` 会遍历所有合并区域，判断当前格子是否在内部，如果是就把对应的边框去掉。

`Grid.Cross` 在网格线的交叉点绘制一个小小的 SVG 十字。这是一个纯装饰元素，但它让网格系统从"布局工具"变成了"视觉语言"。

这些参考线在最终呈现时是极浅的，大多数人可能注意不到。但它们让整个页面有了一种对齐的安心感——像稿纸上的格线一样。

## 导航的悬停序列

导航栏只有四个入口：博客、品味、产品、我的。每个搭配一个小图标。

{/* TODO: 插入导航悬停动画的录屏/动图 */}
{/* ![导航悬停序列](/images/blog/craft-oriensx/nav-hover.gif) */}

我给它们做了一个悬停时的序列动画。不是简单的颜色变化或缩放，而是一个有节奏的多步骤过程：

1. 鼠标悬停，等待 1 秒
2. 图标播放自己的动画
3. 等待 500 毫秒
4. 文字出现闪光扫过
5. 闪光持续 800 毫秒后消失
6. 等待 2 秒，循环

这些全部由一个自定义 hook `useHoverSequence` 编排。核心是嵌套的 `setTimeout`，在每一步结束时检查鼠标是否还在，离开就立刻停止并清掉所有定时器：

```ts
const playSequence = useCallback(() => {
  iconRef.current?.startAnimation();
  addTimer(() => {
    if (!hoveredRef.current) return;
    setIsShimmering(true);
    addTimer(() => {
      setIsShimmering(false);
      addTimer(() => {
        if (!hoveredRef.current) return;
        playSequence();
      }, loopDelay);
    }, shimmerDuration);
  }, shimmerDelay);
}, [addTimer, shimmerDelay, shimmerDuration, loopDelay]);
```

文字闪光（`TextShimmer`）用了双层 `background-image` 配合 `background-clip: text`：底层是纯色作为文字基色，上层是一条移动的高亮渐变带，通过 `backgroundPosition` 动画扫过产生闪光。

整个序列的目的只是让鼠标悬停时，那个小区域有一点"活起来"的感觉。不急不缓。

## 主题切换

主题切换器放在页脚，三个小图标：系统、亮色、暗色。

{/* TODO: 插入主题切换的录屏/动图 */}
{/* ![主题切换](/images/blog/craft-oriensx/theme-switcher.gif) */}

它用了 `AnimatedBackground` 组件——基于 Framer Motion 的 `layoutId` 共享布局动画。所有按钮背后共享同一个 `layoutId` 的半透明背景 div，点击时背景平滑地"滑"到被选中的按钮上。

一个很小的交互，但用对了动画之后，三个按钮之间的切换变得非常自然。

## 最后

回头看这个网站，它的每一个部分都不复杂。边框光束、网格参考线、导航悬停动画、主题切换——单独拿出来都是很小的事情。但把它们放在一起、调到合适的节奏，整体就有了一种气质。

这种气质来自于那些"几乎注意不到"的细节。参考线让页面有了结构的暗示，光束让边缘有了呼吸，悬停序列让导航有了不急不缓的节奏。它们都不显眼，但如果去掉，页面就只是一个页面了。

页脚写着 "Be quiet"，这大概是对整个网站最准确的概括。安静，但不是什么都没有。
