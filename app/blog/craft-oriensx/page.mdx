# 搭建这个网站

再安静性格的人，也有表达的欲望和需求。只是在算法和噪音构筑的广场上，表达往往会被稀释成廉价的情绪。于是我决定亲手建立这块自留地。

对我而言，搭建这个网站的过程是一场关于秩序的实验，我努力追求一种克制的、美丽优雅的呈现。这种美不为悦人，而为自洽。

我的克制在于对内容的挑剔，而我的野心也昭然若现，试图在这里构建一个半衰期极长的思维宫殿。它不仅仅是文字的堆砌，而是我作为一个开发者和思考者，对我自己世界进行拆解和重构的证明。

## 现实降噪

我希望这里像一处修剪整齐、美丽优雅的庭院。这里没有急促的实时反馈，只有植物生长的耐心。

这种表达的欲望，不再是向外的宣泄，更多的是向内的挖掘。我在这片自留地里耕作，将那些狂野的、野心勃勃的想法，驯化成逻辑严密的篇章。

我做的第一件事是画格子。

我想要的更接近建筑图纸上的参考线。我们写字的时候不会去看格线，但格线让字不会歪到一边去，网页上也是同理。

搭了一套 `Grid` 复合组件，技术实现的基本思路来自 Vercel 设计师的[What will you ship?](https://rauno.me/craft/vercel#grid-system)。

画参考线这件事，乍看简单，其实有个根本矛盾。

最常见的做法是：给每个格子画右边框和下边框，再给容器补上上边框和左边框，拼起来就是完整网格。但这种方式要求**每个格子都必须有对应的 DOM 节点**——你得老老实实写满 `rows × columns` 个空 div。

而我们想要的是：只声明行列数，只放需要放内容的格子，参考线自动出现。稀疏布局、跨行跨列的单元格，都要能正常工作。

关键在 `display: contents`。这个属性**让元素的子节点「穿透」到父级**，在布局上仿佛父元素不存在。

对网格来说：参考线层用一个 `display: contents` 的容器包住，里面渲染 `rows × columns` 个绝对定位的 div，每个用 `grid-column-start` / `grid-row-start` 占住对应格子，画右边框和下边框。

容器本身不参与布局，这些 div 在视觉上铺满网格，又不影响真正的子元素排布。而且因为参考线是独立的一层，`Grid.Cell` 用 `row="auto"`、`column="auto"` 时也不会把网格搞乱——没有 `display: contents` 的话，这种写法会直接崩掉。

```tsx
<div className="grid relative">
  {/* 参考线层：contents 让子元素参与网格布局，父容器不占位 */}
  <div className="contents">
    {Array.from({ length: rows * columns }, (_, i) => {
      const x = (i % columns) + 1;
      const y = Math.floor(i / columns) + 1;
      return (
      <div
        key={i}
        className="absolute inset-0 pointer-events-none"
        style={{
          gridColumnStart: x,
          gridRowStart: y,
          borderRight: "var(--gw, 1px) solid var(--border)",
          borderBottom: "var(--gw, 1px) solid var(--border)",
        }}
      />
      );
    })}
  </div>;
  {children}
</div>
```

**响应式**

响应式比较麻烦。桌面 12 列、移动端 1～2 列，列数一变参考线就得重算。桌面和移动各生成一套，用 `max-md:hidden` / `md:hidden` 切换。

`grid-template-columns` 是运行时动态的，Tailwind 的响应式类覆盖不了，只好用 `<style>` 注入媒体查询。不是很优雅，但管用，先用着。

## 捕捉动态灵感

**边框光束：80 秒的呼吸**

网格让页面有了秩序，但秩序太强会显得冷。我想要一点点不那么安分的东西，给这个克制的页面增加一点灵动的感觉。一个安静的房间里，时钟的秒针在走，你不会觉得它吵，但它让安静变得可感知，边框光束就是这个网站的秒针。

<div className="my-8 overflow-hidden rounded relative h-40 bg-card flex items-center justify-center">
  <BorderBeam duration={80} size={50} />
  <div className="text-muted-foreground/20 text-4xl">致 敬 浪 漫</div>
</div>

从 [Magic UI](https://magicui.design/docs/components/border-beam) 找来了 `BorderBeam`，一小截带渐变的光束，沿着视口边缘缓缓地走，80 秒绕一圈。80 秒大概是一个你不会主动去注意、但去掉之后会觉得页面少了点什么的节奏。嗯，是我想要的感觉了。

**导航和链接的悬停**

我做导航的时候一直在想一个问题：悬停反馈应该多快？

大部分网站的做法是鼠标移上去立刻变色或者出现下划线。但我觉得"立刻"有点急。

我想要一种感觉：你把鼠标放上去，什么都不发生，好像这个按钮不太在意你来没来。等一秒，图标慢慢动了一下；再等半秒，文字上有一道光扫过去，像是在提醒你怎么还不点击。然后安静两秒，再循环。

写了个 `useHoverSequence` 来编排这件事。核心就是嵌套的 `setTimeout`，每一步结束时通过 `hoveredRef` 检查鼠标是否还在，不在就停下来：

```ts
const playSequence = useCallback(() => {
  iconRef.current?.startAnimation();
  addTimer(() => {
    if (!hoveredRef.current) return;
    setIsShimmering(true);
    addTimer(() => {
      setIsShimmering(false);
      addTimer(() => {
        if (!hoveredRef.current) return;
        playSequence();
      }, loopDelay);
    }, shimmerDuration);
  }, shimmerDelay);
}, [addTimer, shimmerDelay, shimmerDuration, loopDelay]);
```

鼠标离开的瞬间，`handleLeave` 会一次性清掉所有定时器、停掉图标动画、关掉文字闪光。不等当前动画播完，直接切断。这样即使你快速在几个导航之间划过，也不会残留上一个的动画状态。

文字闪光那个效果叫 `TextShimmer`，可以从 [Motion Primitives](https://motion-primitives.com/docs/text-shimmer) 找到。

原理是用了双层 `background-image` 配合 `background-clip: text`：底层一个纯色 `linear-gradient` 做基色，上层一条窄窄的高亮渐变带，通过 `backgroundPosition` 从右扫到左。

## 最后，Be quiet

这个网站没什么宏大的目的，想着有一个自己的地方，把做过的东西放在一起，坚持写点什么。

大部分时间心思花在了用户可能根本注意不到的地方。80s 绕一圈的光束，1s 后才响应动画的导航及链接，精心处理过的网格，不留边界的导航模糊等这些，单独拿出来都不值一提，加在一起页面就有了一种说不出的“舒服”的感觉。

最后，页脚的 “Be quiet.” 差不多概括了我此时的心境。
