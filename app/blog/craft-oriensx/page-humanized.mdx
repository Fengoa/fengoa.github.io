# 趁碎影还在

信息流涨满了屏幕，通知的繁响在四近，短视频的残影在眼前。是昏沉的夜。

我关了所有 App，向后一仰，靠在椅背上。捏着一个还没写完的想法搁在脑子里。

我在蒙胧中，看见一个安静的页面。

## 收藏夹里的碎影

我逛过很多安静的网站。[Rauno](https://rauno.me) 的留白，[Paco](https://paco.me) 的节制，[Lee Robinson](https://leerob.com) 的清晰，[Vercel](https://vercel.com) 的网格，[wxad.design/abc](https://wxad.design/abc) 的交互分寸感。还有叫不出名字的个人站点，倒映在收藏夹里，随着每一次翻阅，各各夹带了闪烁的灵感，和脑子里的产品逻辑、代码架构，一同荡漾。

诸影诸物，无不解散，而且摇动，扩大，互相融和；刚一融和，却又退缩，复近于原形。边缘都参差如夏云头，镶着屏幕光，发出水银色焰。

一个产品逻辑在脑海里浮动，忽而碎散，拉长了，如缕缕的代码片段，然而没有落地。一种交互美学的直觉也在浮动。产品逻辑一条条全被拉长了，思绪织入交互中，交互织入代码中，代码织入审美中……。在一瞬间，它们又将退缩了。

它们很美。但没有载体的灵感，终究只是水中倒影。

所以我打开了编辑器。

## 网格：稿纸上的格线

我想做的第一件事是画格子。

我收藏夹里那些喜欢的网站，大部分有一种共同的气质：内容看上去是被"放"在某个精确的位置上的，而不是随便排的。我想要这种感觉。不是那种 12 列栅格、Bootstrap 式的工程味，而是更接近建筑制图，或者信纸——你写字的时候不会去看格线，但格线让你的字不会歪。

所以我搭了一套 `Grid` 复合组件。`Grid.System` 是页面级容器，通过 CSS 变量控制参考线宽度。`Grid` 根据行列数自动生成一层透明的边框参考线，绝对定位，`pointer-events-none`，和内容层完全分离。相邻的 Grid 之间通过负 margin 合并边框，不然边线会叠成双倍粗：

```tsx
<div
  className="flex flex-col [&>.grid+.grid]:mt-[calc(var(--guide-width)*-1)]"
  style={{ "--guide-width": `${guideWidth}px` }}
>
  {children}
</div>
```

{/* TODO: 插入网格参考线的截图，展示参考线和十字交叉点 */}
{/* ![网格参考线](/images/blog/craft-oriensx/grid-system.png) */}

比较麻烦的是合并单元格。比如 Hero 区域横跨 10 列的时候，内部那些参考线不应该出现。`getHiddenBorders` 做的事很简单：遍历所有合并区域，看当前格子是不是在某个合并区域内部，是的话把右边框或下边框去掉。

还有一个纯粹的装饰：`Grid.Cross`。它在网格交叉点画一个 20x20 的 SVG 十字，`strokeWidth` 只有 0.6。大多数人不会注意到它。但我觉得这个十字让网格从一个布局工具变成了一种视觉语言。像建筑图纸上的标注符号。

这些参考线在最终呈现时极浅。你不看它，却始终在它的秩序里。

## 边框光束：80 秒的呼吸

从 [Magic UI](https://magicui.design) 看到了 `BorderBeam`，我拿来改了改。

一个带渐变的小方块，金色到紫色再到透明，沿着整个浏览器视口的矩形边缘走。80 秒绕一圈。用了 CSS 的 [offset-path](https://developer.mozilla.org/en-US/docs/Web/CSS/offset-path) 让元素沿 `rect(...)` 路径运动，然后交给 Framer Motion 做 `offsetDistance` 从 0% 到 100% 的无限循环。

{/* TODO: 插入边框光束的录屏/动图 */}
{/* ![边框光束效果](/images/blog/craft-oriensx/border-beam.gif) */}

外层容器用了两层 CSS mask 取交集，只保留边框区域可见：

```css
mask: linear-gradient(transparent, transparent),
      linear-gradient(#000, #000);
mask-clip: padding-box, border-box;
mask-composite: intersect;
```

80 秒。我试过 20 秒，太快了，眼睛会追着它跑。试过 120 秒，太慢了，感觉不到它在动。80 秒刚好是一个你不会主动去注意、但去掉之后会觉得页面少了点什么的速度。

像一小截胭脂水沿着画框缓缓洇开。

## 导航：等一等再动

我做导航的时候一直在想一个问题：悬停反馈应该多快？

大部分网站的做法是鼠标移上去立刻变色或者出现下划线。但我觉得"立刻"有点急。我想要一种感觉：你把鼠标放上去，什么都不发生，好像这个按钮不太在意你来没来。等一秒，图标慢慢动了一下。再等半秒，文字上有一道光扫过去。然后安静两秒，再循环。

{/* TODO: 插入导航悬停动画的录屏/动图 */}
{/* ![导航悬停序列](/images/blog/craft-oriensx/nav-hover.gif) */}

写了个 `useHoverSequence` 来编排这件事。核心就是嵌套的 `setTimeout`。每一步结束时检查鼠标是否还在，不在就停：

```ts
const playSequence = useCallback(() => {
  iconRef.current?.startAnimation();
  addTimer(() => {
    if (!hoveredRef.current) return;
    setIsShimmering(true);
    addTimer(() => {
      setIsShimmering(false);
      addTimer(() => {
        if (!hoveredRef.current) return;
        playSequence();
      }, loopDelay);
    }, shimmerDuration);
  }, shimmerDelay);
}, [addTimer, shimmerDelay, shimmerDuration, loopDelay]);
```

文字闪光那个效果叫 `TextShimmer`，用了双层 `background-image` 配合 `background-clip: text`。底层纯色做基色，上层一条高亮渐变带通过 `backgroundPosition` 从右扫到左。像河水推着一小片光斑慢慢漂过。

我还给四个导航项各画了一个 SVG 动画图标。博客是一个脑子，品味是一颗心，产品是一个仪表盘，我的是一个头像。图标的动画和文字的闪光是串行编排的，不是同时触发。有先后才有节奏。

## 主题切换：一个滑过去的背景

{/* TODO: 插入主题切换的录屏/动图 */}
{/* ![主题切换](/images/blog/craft-oriensx/theme-switcher.gif) */}

页脚右下角三个小图标：系统、亮色、暗色。点一个，后面的背景块带弹簧动画滑过去。

用的是 Framer Motion 的 `layoutId`。三个按钮背后共享同一个半透明 div，哪个被选中了就渲染在哪个按钮的位置上，Motion 自动补间。`bounce: 0.2, duration: 0.3`，有一点回弹但不夸张。

这个交互很小。但切换主题的时候，那个背景块滑过去的 0.3 秒，让整件事情从"点击生效"变成了"物理地移动过去"。

## 排版：一些小的坚持

{/* TODO: 插入文章排版效果的截图，展示标题装饰线、外链箭头、代码高亮等 */}
{/* ![MDX 排版细节](/images/blog/craft-oriensx/mdx-typography.png) */}

博客用 MDX 写。在 `mdx-components.tsx` 里把所有基础 HTML 元素映射到自定义样式。

几个我在意的细节：

H2 标题上方有一条短横线，`before:h-[3px] before:w-6`，用伪元素画的。纯装饰，但让标题不再是光秃秃的一行字。

外链自动带右上角小箭头。有序列表不用默认的 `list-style`，用 CSS `counter` 配合 `before` 伪元素画序号，这样能控制颜色和间距。

代码高亮用 [sugar-high](https://github.com/huozhi/sugar-high)。选它的原因很实际：不到 1KB，零依赖，对一个静态博客来说够用了。亮暗两套配色在 CSS 变量里切换。

`<strong>` 标签除了加粗还加了 `decoration-dotted underline`，一条虚线下划线。图片用 `<figure>` 包裹，alt 文字自动变成 `<figcaption>`。分割线是虚线。

都是小事。但它们加在一起，让文章有了一种排版上的秩序感。

## 还有一些别的

首页标题叫"好的故事"。副标题是"沙漠中融化的雪，加快了春暖花开。"

产品页的标题叫"打造过的一些东西"。我做过交易分析产品、聊天转视频工具、音频处理工具、一个 Figma 插件、一个抽奖 JS 库、一个人脸相似度小程序。它们被装在同样的网格里。

品味页收集了我平时看的东西：Vercel 的设计系统、Radix UI、Syntax.fm 播客。标题叫"提升自己的品味"。

Footer 每 6 秒在版权信息和"Be quiet."之间切换。用 `TextLoop` 做的，文字从下方滑入、向上方滑出。

导航栏固定在顶部，背后是一层 `backdrop-blur-3xl` 配合 CSS mask 渐变做的毛玻璃。底部渐隐到透明，内容在导航栏下方滚动时不会有硬切边。

整站静态导出，部署在 GitHub Pages。Next.js 16，React 19，Tailwind 4，Framer Motion 12。

## 为什么做这个网站

我正要凝视那些碎影时，骤然一惊，睁开眼，页面也已皱蹙，凌乱，仿佛有谁往平静的屏幕上掷了一条推送通知，思绪陡然起立，将整篇的构想撕成片片了。我无意识地赶忙捏住几乎熄屏的手机，眼前还剩着几点光标闪烁的碎影。

我真爱这一个安静的页面，趁碎影还在，我要追回它，完成它，留下它。我关掉通知，欠身伸手去敲键盘——何尝有一丝碎影，只见昏暗的屏幕光，我不在那个安静的页面里了。

但我总记得见过这一篇好的页面，在昏沉的夜。

这个网站就是我"取笔"的动作。把脑海中那个好的故事，趁它还没有彻底碎散，沉淀下来。

页脚写着 "Be quiet"。
