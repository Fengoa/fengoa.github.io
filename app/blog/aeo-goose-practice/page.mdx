# 答案引擎优化：一套可落地的 AEO 能力清单

ChatGPT、Perplexity、Gemini、Grok、Claude、DeepSeek 这类产品，用户已经习惯直接问一句，等一段完整回答。背后是检索增强生成：先去抓网页和第三方信源，再拼成答案。品牌想出现在这段话里，就要让自己**容易被找到、读得懂、值得引用**。

下面这份清单就是按这个目标拆出来的，分四块用：站内先把站点整理清楚，再对齐用户会怎么问，然后布局站外信源，最后用监测把缺口补上。勾选表示「我已经做到」。

## 一、站内：让网站对机器好读

答案引擎会抓页面、解析结构。所以站点不仅要写给人类看，还要让爬虫和模型能稳定抽到正文。

- [ ] 我已经把首页和核心落地页开篇改成一句话说清：**公司是谁、做什么、解决什么问题**，不依赖行业黑话。
- [ ] 我已经理清**标题层级**，并把**列表、常见问题单独成块**，方便模型按块摘取。
- [ ] 我已经配好**结构化数据**（组织、产品、FAQ 等），实体关系更明确。
- [ ] 我已经保证 HTML 干净、摘要可读，**关键正文在公网 HTML 里就能拿到**，不依赖纯客户端渲染。
- [ ] 我已经在页面里补上**参数、案例、数字和可核对的事实**，方便被当作可引用信源。
- [ ] 我已经做好官方**竞品对比页**或「替代方案」页，表格和边界写清楚，方便选型、对比类提问引用。

## 二、场景与意图匹配

传统 SEO 常围着短关键词转。答案引擎这边，用户问的是一整句对话，长尾问题才是主战场。

- [ ] 我已经整理过潜客在不同阶段会怎么问 AI 的**真实问题链**，例如「某领域较好的开源工具有哪些」「适合小团队的某类方案推荐」。
- [ ] 我已经用站内**问答页直接回答这些高频问题**，不只堆功能清单。

## 三、站外：第三方信源也要管

生成答案时，引擎不只看官网，还会去它信任的外部站点找材料。

- [ ] 我已经摸清本行业主流答案引擎常引用的**第三方域名**（如 Reddit、知乎、垂直媒体、测评站、软件目录）。
- [ ] 我已经在这些高频平台上做了**评测收录、社区讨论、百科知识库或稿件投放**，让内容进入公共、可抓取的信源。

## 四、监测、差距分析与攻防迭代

做完基建和内容，还要定期去问一遍，看品牌有没有进答案。

- [ ] 我已经对主流答案引擎建好**固定查询集**，并定期用同一批问题、同一批引擎重跑。
- [ ] 我已经能量化**提及率**、推荐是否靠前，以及相对竞品的**声量份额**。
- [ ] 我已经标出「**竞品总被推荐、自己却缺席**」的具体问题与对应查询。
- [ ] 我已经针对空白点补上 FAQ、落地页、对比页或站外稿件，并在下一轮同一查询集上**验证缺口是否缩小**。

## 工具

清单本身不绑定某一产品。若要用命令行把「监测、审计」自动化，可参考 [Gooseworks](https://gooseworks.ai) 里 Athina AI 的 AEO skill，底层是 `npx goose-aeo@latest`。
