# 卡住时先滚一堆方案：Variant、Banani、Stitch、Uizard

[Variant](https://variant.com/) 往下滚就会不断出界面方案，适合先看方向再动手。[Banani](https://www.banani.co/) 从提示词出多屏稿，可改、可进 Figma。[Google Stitch](https://stitch.withgoogle.com/) 用 Gemini 出界面和设计系统。[Uizard](https://uizard.io/) 从文字生成可编辑原型。

# 网页与微交互灵感：Godly、Awwwards、60fps 这一路

看整站：[Seesaw](https://www.seesaw.website/) 每日手挑网页。[Recent](https://recent.design/) 按 Web、界面、品牌、动效、插画分类刷近期作品。[Godly](https://godly.website/) 量少、手挑。[Awwwards](https://www.awwwards.com/) 体量大，偏实验动效。[SiteInspire](https://www.siteinspire.com/) 筛选更细。[Land-book](https://land-book.com/) 和 [Lapa Ninja](https://www.lapa.ninja/) 专门看落地页。

看细节：[Design Spells](https://designspells.com/) 收微交互、彩蛋和多出来的那些点。[60fps](https://60fps.design/) 和 [Spotted in Prod](https://spottedinprod.com/) 都是已经上线产品里的交互。[Refero](https://refero.design/) 和 [Mobbin](https://mobbin.com/) 按页面类型搜真实产品截图。

# 一批能直接拷走的动效组件库

[React Bits](https://reactbits.dev/) 收集文字、背景和交互动画，按组件拷贝或用 CLI 装，JS/TS、CSS/Tailwind 各有一份。[Magic UI](https://magicui.design/) 和 [Aceternity UI](https://ui.aceternity.com/) 都搭在 React、Tailwind、Motion 上，前者更贴 shadcn/ui，后者偏落地页区块和模板。[Motion Primitives](https://motion-primitives.com/) 更小，开源、可改。

同类还有 [Bundui](https://bundui.io/) 和 [ReUI](https://reui.io/)，同样是 React + Tailwind + Motion。[Cult UI](https://www.cult-ui.com/) 偏 AI 产品界面。[Animata](https://animata.design/) 和 [Eldora UI](https://eldoraui.site/) 是开源动画组件。[Motiq](https://motiq.dev/) 走 shadcn registry，装进去的是可改源码。[21st.dev](https://21st.dev/) 是社区组件市场，里面也能搜到带动画的块。
