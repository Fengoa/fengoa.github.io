# AI Native Organization 术语表

本术语表用于统一「AI Native Organization」系列的核心概念。后续文章沿用以下中英文名称；定义需要调整时，应同步检查相关篇目。

- **环境（Environment）**：影响组织目标、约束与行动结果的外部条件，包括用户、市场、竞争、技术与政策。
- **组织学习率（Organization Learning Rate）**：组织在单位时间内完成有效学习循环的能力。一次有效循环需要产生可靠结论，并将结论转化为组织行为变化。
- **学习循环（Learning Loop）**：组织感知环境变化、形成判断、取得证据并据此改变自身的反馈过程。
- **组织能力（Capability）**：组织在特定约束下持续产生某类预期变化的能力，由经过验证的知识、方法、标准、工具与经验共同构成。
- **实验（Experiment）**：检验判断并产生可比较证据的行动单元。
- **评估（Evaluation）**：依据目标、约束与证据形成判断，并影响后续行动和资源配置的过程。
- **组织运行时（Organization Runtime）**：承载目标、实验、评估、记忆和资源流动，使学习循环持续运行的软件系统。
- **AI 原生组织（AI Native Organization）**：将 AI 作为默认执行基础，并围绕组织学习率设计反馈、协调与适应机制的组织形态。
