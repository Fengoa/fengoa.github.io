五大范式（浅→深）
浅层 ① LLM 作为零样本文本排序器 无微调，直接提示
机制：把用户历史行为转成自然语言 prompt，让 LLM 直接输出推荐结果或打分。无需任何推荐数据微调。

✓ 零样本泛化，冷启动友好
✓ 利用世界知识（知道电影类型、品牌关系）
✗ 完全忽略协同过滤信号
✗ 延迟极高，无法用于在线服务
✗ 对物品 ID 一无所知

浅层 ② LLM 作为语义特征编码器 冻结 LLM，提取 Embedding
机制：用冻结的 LLM 把物品标题/描述编码成语义向量，替代或增强传统 ID Embedding，再接传统推荐模型。

✓ 语义 Emb 解决冷启动
✓ 可与传统 ID 模型结合
✓ LLM 只做离线推断，延迟可控
✗ 冻结 LLM 无法学习推荐偏好
✗ 语义相似 ≠ 用户偏好相似

深层 ④ 语义 ID — 让 LLM 真正"认识"物品 核心突破：离散语义 Token 化物品
机制：用 RQ-VAE / VQ-VAE 把物品编码成一串离散语义 token（如 [42, 7, 156]），这些 token 既有语义含义又捕获协同信号，直接进 LLM 词表，像文字一样处理。

✓ 同时捕获语义 + 协同过滤信号
✓ LLM 可生成新物品 token（泛化）
✓ 与 LLM 预训练框架完全兼容
✗ 量化训练复杂，token 数量爆炸
✗ 量化损失影响精度
